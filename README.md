# CineTech - Avaliação de Filmes 🎬

Atividade prática de integração com a API pública do OMDb (The Open Movie Database).

## 🚀 Funcionalidades
- Busca de filmes pelo título em tempo real
- Exibição de pôster, título e ano de lançamento
- Sistema interativo de avaliação por estrelas (1 a 5 estrelas)

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (Fetch API / Async Await)
